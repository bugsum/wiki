RiftCollector turns any block into an item collector that sweeps up everything dropping around it.
Each collector belongs to the player who placed it, keeps its own storage instead of using the
block's inventory, and can be upgraded, filtered, and set to sell or smelt what it picks up.

## How a collector works

1. A player places a collector. They become its owner, and only one collector fits in a chunk.
2. On its own interval it sweeps the area around it, set by the **pickup range** upgrade, either
   in chunks or in blocks.
3. Everything it finds runs through the collector's filter, then auto smelt, then auto sell, and
   whatever is left is stored.
4. Players open it by right clicking and take items out, or sell the lot from the menu.

:::note[Collectors are not containers]
A collector keeps its own storage, so the block it is placed as is only a skin. Hoppers,
droppers and other plugins cannot pull items out of it, and it has to be empty before it can be
picked back up.
:::

## Quick start

1. Drop the jar into `/plugins` and start the server.
2. Run `/collector` to get a collector item.
3. Place it, right click it, and watch it collect.
4. Edit `plugins/RiftCollector/config.yml`, then run `/collector reload`.
